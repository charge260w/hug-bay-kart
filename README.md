# 晚霞抱抱湾 · 星愿赛车

一关温柔的 3D 休闲赛车游戏：紫色毛绒小车、车顶精灵、两圈晚霞赛道、三个陪跑对手，以及星星收集、漂移小喷、氮气加速和暖心音效。

## 开始游戏

打开 https://charge260w.github.io/hug-bay-kart/ ，点击「出发，去兜风」。

- 左右方向键 / A、D：转向（自动油门）。
- 空格 + 转向：漂移蓄力，松开后小喷。
- Shift：氮气加速；下方向键 / S：刹车。
- P / Esc：暂停；手机支持屏幕触控按钮。

声音在点击出发后启用，中文语音取决于设备可用语音。游戏提供画质切换、静音和无 WebGL 时的轻量模式。最佳记录仅保存在当前浏览器。

`index.html` 为完整单文件版本，可下载后离线打开。3D 模型可通过游戏中的模型按钮导出为 GLB。

Three.js r128 与 GLTFExporter 的 MIT 许可见 `THREE-LICENSE.txt`。
