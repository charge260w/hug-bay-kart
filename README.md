# 柿柿如意 · 宫苑秋日体感赛车

以故宫建筑色彩与秋日柿林为灵感的原创 3D 赛车。红柿色小车载着喜柿和橙意，经过朱墙宫门、金瓦宫苑、柿子树与拥抱站，收集立体柿子。非故宫或电视节目官方作品。

[在线游玩](https://charge260w.github.io/hug-bay-kart/)

## 操作

- 左右键 / A、D：向画面左、右转向。
- 空格 + 转向：漂移；Shift：加速；下方向键 / S：刹车。
- P / Esc：暂停；手机提供触屏按钮。
- 开启摄像头后自然看向镜头校准：左歪头向左，右歪头向右；微笑漂移，点头加速。
- 摄像头下方可重新校准或反转方向。画面仅在本机识别，不上传、不录制、不保存。拒绝摄像头仍可按键游玩。

五声音阶程序化音乐、收集音、加速音、伙伴提示音与设备支持的中文语音。收集、微笑与点头会增长喜柿亲密度。

## 实现与验证

index.html 为入口，palace-theme.js 构建原创宫苑、柿子树和角色。Three.js r128 与 MediaPipe Face Mesh 0.4.1633559619 均由本仓库提供；许可见 vendor 内文件。模型按钮可导出红柿小车 GLB。

方向修复采用与跟车镜头一致的赛道右向量，同步车头朝向与路面法线。检查覆盖 12 处赛道的画面投影、左右按键、模拟原始脸部关键点、柿子收集、终点及手机布局。真实摄像头需玩家授权与校准。
