# 西关星愿赛车 · 老广州体感之旅

一关以紫色毛绒 NX8 小车与车顶精灵“啵啵”为主角的 3D 体感赛车游戏。赛道穿过永庆坊、西关骑楼、珠江码头和花城灯火，沿途有老电车、茶楼、红灯笼、茶宠补给站与暖心语音。

在线游玩：https://charge260w.github.io/hug-bay-kart/

## 体感玩法

点击“开启体感”或“出发，饮早茶”后允许摄像头：

- 头向左、右歪：转向。
- 微笑：持续漂移，松开表情后触发小喷。
- 点头：消耗星愿氮气加速。
- 识别框下方可重新校准或反转体感方向。

摄像头画面只在当前设备中交给 MediaPipe Face Mesh 识别，不上传、不录制、不保存。拒绝权限、无摄像头或识别组件无法加载时，游戏会保留以下操作：

- 左右方向键 / A、D：转向。
- 空格 + 转向：漂移；Shift：氮气；下方向键 / S：刹车。
- P / Esc：暂停；手机可使用屏幕按钮。

## 宠物陪伴

收集星星、微笑和点头会提升啵啵亲密度。啵啵会跟随头部动作摇摆，在老广州不同街区用声音和文字陪伴玩家；撞到护栏时也不会扣快乐分。

## 技术与许可

`index.html` 为游戏入口。Three.js r128 负责 3D 场景，MediaPipe Face Mesh `0.4.1633559619` 负责本机脸部关键点识别。许可文件位于 `vendor/THREE-LICENSE.txt` 与 `vendor/face_mesh/LICENSE`。
